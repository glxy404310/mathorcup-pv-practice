【4. 实际功率与理论可发功率的偏差分析】
============================================================================================

  分析框架（乘法分解，把两类损失彻底分开）:
      P_real = P_theo(晴空) × [POA_实测/POA_晴空] × PR
      其中 PR = P_real / P_theo(实测辐照) -> **非辐照损失**
                 （逆变器/线损/积灰/失配/温度效应）
           [POA_实测/POA_晴空]           -> **天气（云/气溶胶）造成的辐照折减**
      PR 的定义不依赖辐照绝对标度，因此不受辐照传感器系统偏差影响，
      是比"P_real/P_theo(晴空)"更稳健的效率度量。
      另单独给出水平面口径的天气折减 kc = GHI_实测/GHI_晴空（用于气象侧解读）。

  非辐照损失效率 PR = P_real / P_theo(实测辐照)（n=11531）
    均值 0.7820  中位 0.7925  标准差 0.2041
    P05 = 0.4619
    P25 = 0.6397
    P50 = 0.7925
    P75 = 0.9244
    P90 = 1.0320
    P95 = 1.1041
    P99 = 1.2000
    PR>1 的占比 = 13.84%  （PR 物理上应 <1；>1 的点来自辐照传感器偏差与量测噪声）

  天气折减因子 kc = GHI_实测 / GHI_晴空（水平面口径，n=11245）
    均值 0.8535  中位 0.8836
    P05 = 0.2505
    P25 = 0.5513
    P50 = 0.8836
    P75 = 1.1326
    P90 = 1.3506
  倾斜面口径折减 POA_实测/POA_晴空: 均值 0.8256 中位 0.8462

  损失分解（相对「假设无云且系统理想」的基准）:
    理想工况 PR（取 P95，截断到 1.0）= 1.0000
    平均 PR = 0.7820  -> 系统侧损失 = 0.2180 (21.8%)
    平均 kc = 0.8535  -> 天气侧损失 = 0.1465 (14.7%)
    实际出力/理想出力 = PR x kc = 0.6674，总损失 = 0.3326 (33.3%)
    注：两项损失是**相乘**关系（(1-系统损失)(1-天气损失)），故各自百分比
        相加会超过总损失，不可用加法归因。
    相对贡献（按损失量级比较）：系统侧 59.8%，天气侧 40.2%

    结论：**天气侧的辐照折减与系统侧效率损失量级相当**，两者都不可忽略；
          但系统侧损失在训练期可被标定吸收（近似常数），
          而天气侧损失逐时刻变化、无法用常数刻画 —— 因此提升预测精度的
          关键是准确刻画云/辐照过程。这直接支撑问题2/3 的建模重点，
          也解释了为何 NWP 辐照是首要特征（见问题3的置换重要性）。

⚠️ 数据质量限制（须写入论文）
--------------------------------------------------------------------------------------------
  该站实测 GHI 有 713 个白昼样本**超过大气层外辐照上限**（物理不可能），
  且实测峰值达上限的 0.97 倍，指示辐照传感器存在约 10~14% 的正向偏差。
  证据链：(a) 超大气层外上限的样本存在；(b) 该偏差在 LN=1~6 全区间内近乎恒定，
            与浑浊度取值无关，故非模型问题；(c) 功率侧交叉验证得到的 PR 中位
            仅 0.793，低于维护良好电站应有的 0.78~0.85。
  影响与应对：该偏差的绝对标度被单参数功率曲线模型（power_curve.py）的 eta 吸收，
            故对问题2/3 的**预测精度**影响有限；但问题1的偏差归因必须声明此不确定性。
