# 第一问晴空参考模型与参数

当前主站station08。参考曲线用于解释实际功率与简化物理工况的差异，不是日前预测，也不是严格功率上限。具体实现见 `src/q1_reference_power.py`，station08参数以 `q1_reference_assumptions_station08.json` 为准。

采用太阳位置 → Ineichen晴空辐照 → isotropic板面辐照 → 固定25°C组件DC功率 → PVWatts逆变器AC输出。基准不通过实测功率拟合。

| 参数 | station08（主站） | station01（对比） |
| --- | --- | --- |
| 经度/纬度 | 113.89999°E / 36.70761°N | 117.45722°E / 38.18306°N |
| 朝向/倾角 | 朝南 / 33° | 朝南 / 33° |
| 组件数×额定功率 | 78042×265 Wp | 74000×270 Wp |
| 组件DC额定容量 | 20.68113 MWp | 19.98 MWp |
| 假设交流限制 | 20 MW | 20 MW |

共同假设：海拔0m（另以200m作敏感性）、反射率0.25、固定组件温度25°C、逆变器额定效率0.96、额外损耗0%/10%/20%。组件数量和规格来自元数据，其余假设不代表已核实的设备或环境参数。

DC参考功率为组件DC额定容量×板面辐照/1000×(1−额外损耗)。逆变器DC输入限制为20/0.96 MW，与组件DC额定容量分别定义。额外损耗与逆变器损耗分别计算。实际功率与参考的MAE不能称为预测误差。

逐点结果、参数与哈希在 `results/q1/<站点>/reference_power.csv` 和 `reference_summary.json`；主站敏感性表为 `results/q1/station08/reference_sensitivity.csv`。月度、日内和波动分析已完成，见第一问交接稿。完整运行命令统一见根目录README。
