# 第一问参考功率方案：station01，v1

当前阶段：在用户确认“目前只有ZIP，先记录缺口并做明确假设下的参考方案”后，建立可复现的第一版简化参考模型。以下假设不是站点已核实参数，后续有资料时应替换并重跑。

## 计算路线

经纬度与UTC时间 → 太阳位置 → Ineichen晴空GHI/DNI/DHI → 朝南33°板面辐照 → 固定组件温度下的DC参考功率 → 假设逆变器与交流限制 → AC参考功率。

组件参考工况固定为25°C，近似把板面辐照作为有效辐照：

```text
组件额定直流容量 = 74000 × 270 Wp = 19.98 MWp
P_dc_ref(W) = 19.98 × 10^6 × G_poa(W/m²) / 1000 × (1 - 额外损耗率)
逆变器DC输入限制 = 假设AC限制 / 假设额定效率 = 20 MW / 0.96
P_ac_ref = PVWatts逆变器模型(P_dc_ref, 逆变器DC输入限制, 额定效率0.96)
偏差 = power_clean - 0%额外损耗情景的P_ac_ref
```

额外损耗不包含逆变器效率，两者分别计算，避免重复扣除。PVWatts逆变器函数的pdc0表示逆变器DC输入限制，不能与19.98 MWp组件额定容量混用。

## 参数、来源与假设

| 参数 | 使用值或方案 | 依据与限制 |
|---|---|---|
| 经纬度 | 117.45722°E、38.18306°N | metadata.csv，station01行 |
| 倾角、方位角 | 33°、180°（朝南） | 元数据South 33°；方位角采用正北0°顺时针约定 |
| 组件数、单组件额定功率 | 74000、270 Wp | 元数据Panel_Number、Module中的Pmax；合计19.98 MWp |
| 装机容量 | 元数据20000 kW | 接近组件额定容量，仍不能据此确定其AC/DC口径 |
| 海拔 | 基准假设0m，另算200m敏感性情景 | 均不是站点真实海拔 |
| 晴空辐照 | Ineichen模型，pvlib内置气候浑浊度 | 不使用实际功率拟合，不等于逐时真实天气 |
| 板面辐照 | isotropic散射模型，地面反射率0.25 | 简化各向同性散射；反射率采用函数默认参考值，不是现场测量 |
| 组件温度 | 固定25°C参考工况 | 忽略真实冷热变化；现场气温不能直接当组件温度 |
| 有效辐照 | 近似等于板面辐照 | 未加入入射角、光谱、阴影等细节；不是完整PVWatts系统模型 |
| 交流侧口径 | 暂把实测power理解为交流输出，交流限制假设20 MW | 未核实逆变器台数、电站交流容量和实测AC/DC口径 |
| 逆变器 | PVWatts模型，额定效率0.96 | 采用通用模型默认值，不是TC500KH的实测效率 |
| 额外损耗 | 基准0%，另算10%、20% | 是参考与敏感性情景，不是拟合或现场测量的损耗率 |
| 时间对齐 | 把时间戳作为采样时刻，计算点值参考 | 瞬时/平均、区间头尾尚未确认；后续不能无条件用来算精确电量 |

## 输出与使用边界

- `results/q1/station01/reference_power.csv`：逐时刻太阳位置、晴空辐照、板面辐照、DC/AC参考功率、实际功率和偏差。
- `results/q1/station01/reference_sensitivity.csv`：所有情景在共同有效白昼点上的比较。这里的MAE是实际与物理参考的差异，不是日前预测误差。
- `results/q1/station01/reference_summary.json`：参数假设、数据哈希、版本和结果。
- `figures/q1/station01_reference_day.png`：固定诊断日2018-08-25的实际/参考对比，不声称代表全年。
- 清洗功率缺失时，偏差也保持缺失；白昼零功率仍保留。基准不使用NWP或现场天气，也没有从实测功率拟合参数。
- 实际功率可能超过参考值；云边增强、低温、简化假设和参数口径等均可能影响，不能把参考曲线当成任何天气下的严格上限。
- 本次只建立参考曲线。第一问尚需月度或季节变化、平均日内形状、短时波动、偏差解释和敏感性讨论。

## 角色B现在可以做的三个小任务

1. 在项目目录运行`.venv/bin/python src/q1_clean_data.py`，打开清洗摘要，确认能复现结果；不必修改原始数据。
2. 阅读异常对照图，用自己的话写两句：为什么持值重复点设缺失？为什么白昼有辐照却零功率不能直接删除？
3. 运行`.venv/bin/python src/q1_reference_power.py`，打开参考方案与参考日图，解释“19.98 MWp来自组件资料，20 MW交流限制仍是假设”，并将仍不理解的术语记下来。

这些任务的目的是让B能向A/C解释代码口径。以后拿到额外资料，再补充海拔、功率采样口径、容量口径和逆变器参数。

## 方法来源

- [pvlib晴空模型接口](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.location.Location.get_clearsky.html)：Ineichen晴空辐照及气候参数。
- [pvlib板面辐照接口](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.irradiance.get_total_irradiance.html)：直射、天空散射和地面反射分量；isotropic和反射率默认值。
- [PVWatts DC模型公式](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.pvsystem.pvwatts_dc.html)：固定组件温度25°C时温度项为1；本方案另明确忽略入射角等影响。
- [PVWatts逆变器模型](https://pvlib-python.readthedocs.io/en/stable/reference/generated/pvlib.inverter.pvwatts.html)：额定效率、DC输入限制与AC削顶关系。
